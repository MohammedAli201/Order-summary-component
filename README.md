# Order Summary Component

A static HTML and CSS implementation of an order-summary card.

## Run

Open `index.html` in a browser. No package installation is needed.

`styles.css` contains the card styling and `style-guide.md` records the supplied design specification.

## Scope and attribution

This is a UI learning exercise based on a Frontend Mentor challenge. Buttons are presentation elements, not a live checkout. See [Frontend Mentor](https://www.frontendmentor.io/).
